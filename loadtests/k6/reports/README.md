# k6 테스트 리포트

테스트별 Grafana 관측 결과와 k6 실행 결과를 정리하는 위치입니다.

새 리포트를 작성할 때는 `template.md`를 복사해서 사용합니다.

파일명 예시:

```text
ATK-A02-hot-row-lock-2026-05-03.md
SMOKE-order-create-2026-05-03.md
```

리포트는 Grafana 캡처만 모으는 문서가 아니라, 테스트 가설과 관측 결과를 연결해서 결론을 남기는 문서입니다.

권장 작성 흐름:

```text
1. 실행 조건 기록
2. Grafana 대시보드 캡처 첨부
3. k6 터미널 결과 요약
4. 서버 로그/DB 상태 확인
5. 가설 재현 여부 결론
6. 후속 조치 정리
```
