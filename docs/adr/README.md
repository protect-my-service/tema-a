# ADR (Architecture Decision Records)

아키텍처 의사결정 기록. 각자 내린 결정(특히 W3 비동기 순서 보장 방어 선택)을 누적한다.

## 규칙
- 파일명: `NNNN-{slug}.md` (예: `0001-transactional-outbox.md`). `NNNN`은 0001부터 증가하는 4자리.
- 작성: `0000-template.md`를 복사해 채운다.
- 목표: W3 종료 시점까지 **본인 ADR 3건 누적**.
- 한 ADR = 하나의 결정. 결정의 **맥락(Context)·대안·근거·결과(Consequences)·트레이드오프**를 담는다.
